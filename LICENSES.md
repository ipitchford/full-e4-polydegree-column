|---|---|
| Original manuscripts, project documentation, project-created ledgers/data, receipts, and public internal-review records | CC0-1.0 |
| Original executable Python and workflow code outside `formal/BorderedJacobianUniversal/` | MIT (`LICENSE-CODE`) |
| `formal/BorderedJacobianUniversal/` Lean source and its verifier | Apache-2.0 (licence retained in that directory) |
| Bibliographic facts and citation metadata | Facts are not restricted; cited texts retain upstream rights |

| Python-FLINT/FLINT/Arb, SymPy, Mathlib, Lean, Pandoc, TeX, GitHub Actions, and fonts | Not redistributed as dependencies; upstream licences apply |
| Third-party papers and historical source archives | Not included in this public projection |

The grants apply only where the project contributors have the necessary
rights. They do not override third-party terms.
